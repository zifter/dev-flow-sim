# Правила работы в репо

- Отвечай по-русски. Интерфейс и README тоже на русском.
- Репо публичный, аккаунт `zifter`. Коммиты только под `zifter <zifter.ai@gmail.com>`, рабочий email сюда не попадает. Перед коммитом проверь `git config user.email`.
- Никаких данных работодателя: названий компаний, людей, внутренних цифр. Пример в `example.js` условный.
- Без сборки и зависимостей: `index.html` открывается файлом, библиотеки только с CDN при реальной необходимости.
- Логику модели держи в `sim.js`, интерфейс в `index.html`. После правок модели запускай `node --test test/`. Новое поведение модели покрывай тестом.
- Изменил модель, метрику или схему конфига — обнови README.
